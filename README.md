# Realty Telegram Bot

Бот принимает ссылки на объявления недвижимости, публикует их в каналы и
распределяет заявки между риелторами.

## Финальная логика

1. Ссылки на DOM.RIA, OLX и другие площадки принимает только владелец,
   указанный в `MY_TELEGRAM_ID`. Сообщения всех остальных пользователей для
   создания объявлений игнорируются.
2. При публикации в публичный канал добавляется кнопка
   `📅 Записаться на просмотр`. Она открывает WebApp-форму внутри Telegram.
3. Клиент указывает имя и телефон, нажимает `Передать номер телефона`, после
   чего форма отправляет заявку серверу и закрывается. Клиент остаётся в канале
   и не переходит в чат с ботом.
4. В рабочую группу приходит карточка без имени и номера клиента. На карточке
   остаётся только кнопка `📥 Взять заявку`.
5. Первый риелтор получает полные данные в личном сообщении, а карточка в группе
   заменяется на сообщение о том, кто перехватил заявку. Закрепление защищено
   атомарным обновлением SQLite.

## Запуск

```bash
python main.py
```

Python-зависимости не нужны: парсер, HTTP-сервер WebApp и SQLite используют
стандартную библиотеку. Доступ к Telegram API идёт через установленный
Replit Telegram connector bridge, поэтому токен бота не хранится в проекте.

## Переменные окружения

```text
MY_TELEGRAM_ID=123456789
WORKGROUP_CHAT_ID=-1001234567890
PUBLIC_CHANNEL_ID=-1009876543210
WEBAPP_URL=https://your-public-domain.example/api
REALTY_WEBAPP_PORT=8090
PUBLIC_REALTOR_CONTACTS=Свяжитесь с риелтором в Telegram
```

`MY_TELEGRAM_ID` — обязательный Telegram ID владельца. Пока он не настроен,
бот намеренно игнорирует все сообщения для создания объявлений.

`WEBAPP_URL` должен быть публичным HTTPS-адресом API-сервиса, который
проксирует WebApp на этот процесс (в текущем artifact routing это адрес
с суффиксом `/api`).
Если переменная не указана, бот пытается использовать автоматически доступный
`REPLIT_DEV_DOMAIN`. Внутренний порт Python WebApp задаётся через
`REALTY_WEBAPP_PORT` (по умолчанию `8090`).

По совместимости `WORKGROUP_CHAT_ID` при отсутствии берётся из
`PRIVATE_CHANNEL_ID`. Публичный канал можно переопределить через
`PUBLIC_CHANNEL_ID`.

## База данных

Создаётся файл `data/leads.db` с таблицами:

- `listings` — объекты и ID сообщений;
- `leads` — имя, телефон, Telegram username, статус заявки и назначенный
  риелтор.

Номер и имя клиента не отправляются в рабочую группу до успешного закрепления.

## Telegraph

Для полной публичной карточки бот по-прежнему создаёт Telegraph-страницу с
фотографиями и описанием. Access token автоматически сохраняется в
`data/telegraph_access_token.txt`. При необходимости можно задать
`TELEGRAPH_ACCESS_TOKEN`, `TELEGRAPH_SHORT_NAME` и `TELEGRAPH_AUTHOR_NAME`.

## Важное ограничение Telegram

Telegram не разрешает поле `web_app` в inline-кнопках сообщений каналов:
официально оно доступно только в личном чате пользователя с ботом. Поэтому
кнопка канала использует HTTPS-ссылку на тот же Telegram WebApp. В Telegram она
открывается во встроенном окне поверх канала и после отправки закрывается без
перехода в чат с ботом.

Страницы, которые полностью рендерятся JavaScript, защищены антиботом или
прячут изображения за авторизацией, могут потребовать отдельного адаптера
парсера.
